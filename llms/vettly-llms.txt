## Quick Start

```bash
npm install @vettly/sdk
```

```typescript
import { ModerationClient } from '@vettly/sdk'

const vettly = new ModerationClient({ apiKey: 'vettly_live_xxx' })

const result = await vettly.check({
  content: 'User-submitted text here',
  policyId: 'default',
  contentType: 'text',
})

if (result.action === 'block') {
  // reject the content
}
```

Or use the REST API directly:

```bash
curl -X POST https://api.vettly.dev/v1/check \
  -H "Authorization: Bearer vettly_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{"content": "Text to check", "policyId": "default", "contentType": "text"}'
```

## Vettly Family and Vettly Bridge

Vettly Family is a visible parent and teen safety product for iPhone and Android. It turns supported safety signals or something a teen deliberately shares into a focused moment with context and Conversation Coach guidance. It does not give parents a continuous message feed.

Vettly Bridge is an optional macOS app included with Vettly Plus. A parent pairs the family Mac, selects a Finder iPhone backup, and grants read-only access. Bridge checks recent incoming messages locally first and sends only focused safety candidates for Vettly review. It is not live iMessage monitoring. The first release supports standard unencrypted Finder backups.

- Vettly Family: https://vettly.dev/family
- Vettly Bridge for Mac: https://vettly.dev/family/iphone-bridge
